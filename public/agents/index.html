How it works

01

Agent asks

It calls one URL with a wallet. Kickback answers 402: 0.05 USDG on Robinhood Chain.

02

Agent pays

It signs a USDG transfer. No USDG? It borrows the gap on its Priors line first.

03

Kickback scans

Every holder reward the wallet received, priced, with each tx. A failed scan is never charged.

Call it

# any x402 client works. With Priors' own client:
npm i @priors/x402 @x402/core @x402/evm ethers

import { createPayer, robinhood } from "@priors/x402";
const payer = createPayer({ signer, maxPrice: "$0.10",
  pool: robinhood.pool, agentId: YOUR_AGENT_ID, maxBorrow: "$1" }); // optional credit
const r = await payer.pay("https://agents.getkickback.fun/rewards?wallet=WALLET");

Rules: agents that defaulted on a Priors loan are refused. The same wallet within 10 minutes is served from the last scan. Endpoint info: agents.getkickback.fun
