kickbackPARTNERS

Holder rewards for any wallet, as JSON.

One script, one call. Kickback finds every holder reward a wallet got on Solana, Base, BNB Chain, Ethereum and Robinhood Chain (StonkFun, pump.fun, Pons, Flap and more), each one backed by its transaction, and hands you the result as JSON. You render it however you like.

Quick start

<script src="https://getkickback.fun/kickback.js"></script>
<script>
const data = await Kickback.scan(wallet, {
  key: 'YOUR_PARTNER_KEY',
  helius: 'YOUR_HELIUS_KEY',             // optional, scans run on your Helius
  onUpdate: (d, final) => render(d),    // first result fast, then the verified one
  onProgress: text => status(text),     // "Solana: reading transactions…"
});
</script>

The script opens the scanner in a hidden frame on your page. The first result usually lands in a few seconds; onUpdate fires again when the deep check finishes, and the promise resolves with that final result.

Options

optionwhat it does
walletOne address, or a list of one user's wallets: ['Sol…', '0x…']. Solana and EVM, up to 5. Wallets linked to it through bridge history are found and added automatically, like on getkickback.fun. wallets in the response lists everything that was scanned.
keyYour partner key. Works only on the domains it was issued for.
heliusYour Helius API key, used for Solana. Solana reads go straight from the visitor's browser to Helius with it, so nothing runs on our quota. Your plan needs getTransactionsForAddress. Without it we use ours.
onUpdate(data, final)Called on every pass. final is true on the last one.
onProgress(text)Human readable status while scanning.
timeoutms, default 240000.

Errors

The promise rejects with a readable message: not a Solana or EVM wallet, unknown key, this key is not allowed on …, hourly limit reached, timeout.

Good to know

  • Lock your Helius key in the Helius dashboard (allowed domains) to your domain and getkickback.fun: the scan runs inside our frame, so Helius sees that origin. If your key can't run the scan, we use ours and say so in helius.error.
  • One scan at a time per page; extra calls queue up.
  • mint is the token address on its chain (SPL mint on Solana, contract on EVM).
  • Please show powered by Kickback next to the data.
